# ITAI 1371 — Course Notebooks

This workspace contains the Jupyter notebooks and lab materials for ITAI 1371.

## Project structure

- `module-2/` — Module 2 lab: `L02_MelanieVillela_ITAI1371.ipynb` — explores core ML tools (Colab, Jupyter, pandas, NumPy, Matplotlib, scikit-learn) by loading, analyzing, and visualizing the Iris dataset.
- `module-3/` — Module 3 lab: `L03_MelanieVillela_ITAI1371.ipynb` — walks the full ML workflow, building and evaluating classification models on the Wine dataset.
- `module-4/` — Module 4 lab: `L04_MelanieVillela_ITAI1371.ipynb` — performs exploratory data analysis on the Titanic dataset to surface missing values, outliers, and key relationships.
- `module-5/` — Module 5 lab: `L05_MelanieVillela_ITAI1371.ipynb` — covers data preprocessing on the Titanic dataset, including median imputation, one-hot encoding, and feature scaling.
- `module-6/` — Module 6 lab: `L06_MelanieVillela_ITAI1371.ipynb` — practices both regression and classification workflows (fare regression and survival prediction) on the Titanic dataset.
- `module-7/` — Module 7 lab: `L07_MelanieVillela_ITAI1371.ipynb` — focuses on model evaluation using precision, recall, and cross-validation.
- `module-8/` — Module 8 lab: `L08_MelanieVillela_ITAI1371.ipynb` — visualizes the bias-variance tradeoff and over/underfitting using polynomial regression models.
- `module-9/` — Module 9 lab: `L09_MelanieVillela_ITAI1371.ipynb` — compares a Decision Tree to a Random Forest ensemble on the Iris dataset and analyzes feature importance.
- `module-10/` — Module 10 lab: `L10_MelanieVillela_ITAI1371.ipynb` — applies K-Means clustering and PCA for unsupervised segmentation and dimensionality reduction.
- `module-11/` - Module 11 lab: `L11_MelanieVillela_ITAI1371.ipynb` — covers hyperparameter tuning (Grid/Random Search) and an introduction to AutoML with AutoGluon.
- `module-12/` - Module 12 lab: `L12_MelanieVillela_ITAI1371.ipynb` — audits a model trained on the Adult dataset for algorithmic bias and fairness across demographic groups.
- `module-13/` - Module 13 lab: `L13_MelanieVillela_ITAI1371.ipynb` — refactors manual preprocessing into scikit-learn Pipelines to build reproducible workflows and prevent data leakage.
- `final/` — Final project: `FP_ProjectTopic_MelanieVillela.ipynb` — classifies the sentiment of Reddit comments on the Israel-Palestine conflict, comparing Logistic Regression, Naive Bayes, and Random Forest models trained on TF-IDF text features. See [final/README.md](final/README.md) for details.

## How to use

1. Open the folder in VS Code.
2. Open any notebook file in the VS Code Notebook Editor.
3. Run cells interactively or launch a Jupyter server from the terminal:

   `jupyter notebook`

4. Follow the instructions inside each notebook to complete the lab exercises.
